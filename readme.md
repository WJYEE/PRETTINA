# PRETTYNA

> 30일 동안 나를 꾸준히 가꾸고 성장시키기 위한 개인용 모바일 Habit Tracker.

---

## 1. Project Goal

PRETTYNA는 최소 30일 동안 사용할 개인용 자기관리 웹앱이다.

목표는 크게 두 가지다.

### 💗 PRETTY

외적인 자기관리와 건강한 생활 습관을 꾸준히 실천한다.

### 🧠 BRAIN

취업, 공부, 지식, 언어 등 내적인 성장을 위한 활동을 꾸준히 실천한다.

이 앱은 게임이나 캐릭터 육성 서비스가 아니다.

복잡한 경험치나 보상 시스템보다 **오늘 무엇을 했는지 빠르게 기록하고, 전체 진행 상황을 한눈에 확인하는 것**을 가장 중요하게 한다.

---

# 2. MVP Principles

## 개발 우선순위

1. 모바일에서 편하게 사용할 수 있을 것
2. 기록하는 데 시간이 오래 걸리지 않을 것
3. 오늘 해야 할 일을 한 화면에서 파악할 수 있을 것
4. 비슷한 행동은 하나의 카테고리 안에 묶을 것
5. 체크와 입력 과정에서 불필요한 선택지를 최소화할 것
6. 지난 기록을 날짜별로 확인할 수 있을 것
7. 30일간의 전체 진행 상황을 한눈에 볼 수 있을 것

# 10. 📊 DASHBOARD

Dashboard의 목적은 **30일 동안 내가 얼마나 꾸준히 나를 관리했는지 한눈에 보는 것**이다.

복잡한 분석 기능은 만들지 않는다.

---

## 30 Day Progress

상단에 전체 진행도를 표시한다.

예:

`DAY 07 / 30`

7일째라면 30일 중 현재 위치를 progress bar로 보여준다.

---

## Today's Progress

* 전체 %
* PRETTY %
* BRAIN %

---

## 30 Day Calendar

30개의 날짜를 작은 셀 형태로 보여준다.

각 날짜는 해당 날짜의 달성률에 따라 시각적으로 구분한다.

날짜를 누르면 해당 날짜 기록을 확인할 수 있다.

---

## Habit Summary

각 주요 습관의 30일 수행 횟수를 표시한다.

예:

* 6시 기상 `18 / 30`
* 운동 `21 / 30`
* 괄사 `24 / 30`
* 스킨케어 `27 / 30`
* 식단 `20 / 30`
* 뉴스 `19 / 30`
* 데이터 공부 `22 / 30`
* 언어 공부 `25 / 30`

---

## Body Changes

신체 측정값이 2회 이상 존재할 경우 변화량을 표시한다.

예:

`허리 72 → 69 cm`

값이 부족하면 표시하지 않는다.

---

# 11. Completion Rules

시간 목표가 있는 습관은 목표 시간을 충족하면 자동으로 완료 처리한다.

예:

* 뉴스 20분 이상 → 완료
* 면접 30분 이상 → 완료
* 데이터 공부 30분 이상 → 완료
* 언어 공부 30분 이상 → 완료
* 운동 30분 이상 → 완료

단순 행동은 checkbox를 사용한다.

사용자가 체크할 필요가 없는 행동은 해당 날짜의 달성률 계산에서 제외할 수 있어야 한다.

---

# 12. Data Structure

모든 기록은 날짜 기준으로 저장한다.

예:

```ts
{
  "2026-08-18": {
    pretty: {},
    brain: {},
    record: {}
  }
}
```

localStorage에 저장한다.

날짜가 변경되면 새로운 Daily Record를 생성한다.

기존 날짜 데이터는 삭제하지 않는다.

---

# 13. UI / UX

전체 디자인은 다음 방향을 따른다.

* Mobile First
* 깔끔함
* 귀엽지만 유치하지 않음
* 자기관리 / 라이프스타일 앱 느낌
* 카드 기반 UI
* 충분한 여백
* 한 손으로 조작하기 쉬운 크기의 버튼
* 입력 단계 최소화
* 긴 설명 최소화
* 중요한 정보만 기본 노출
* 세부 입력은 펼치기/접기 가능

체크했을 때 즉각적인 시각적 피드백을 제공한다.

---

# 14. Important UX Rule

PRETTYNA의 핵심은 기록 자체가 일이 되지 않게 하는 것이다.

따라서:

* 같은 종류의 행동은 하나의 카드에 묶는다.
* 불필요한 팝업을 만들지 않는다.
* 저장 버튼을 반복해서 누르게 하지 않는다.
* checkbox 변경 및 입력값은 자동 저장한다.
* 자주 사용하는 화면까지 최대한 적은 터치로 접근한다.
* Today 화면에서 대부분의 일일 기록을 끝낼 수 있게 한다.

---

# 15. MVP Scope

현재 MVP에서는 다음 기능을 구현하지 않는다.

* 로그인
* 회원가입
* 서버 DB
* 캐릭터
* XP
* Level
* 게임 재화
* 랭킹
* SNS
* 커뮤니티
* AI 추천
* 알림 시스템
* 복잡한 통계 분석

현재 목표는 **30일 동안 실제로 매일 사용할 수 있는 빠르고 단순한 개인용 Habit Tracker를 완성하는 것**이다.
